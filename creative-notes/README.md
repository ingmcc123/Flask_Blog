# 창작노트

키워드와 장르를 입력하면 **제목 · 로그라인 · 캐릭터 프로필 · 16화 완결 회차별 줄거리**를 생성하는 소설 창작 보조 웹앱입니다.

## 실행

```bash
cd creative-notes
npm install
npm run dev
```

브라우저에서 표시된 주소(기본 `http://localhost:5173`)로 접속합니다.

## 사용법

1. 키워드(쉼표·공백 구분)와 장르를 입력합니다.
2. **노트 생성하기**를 누르면 입력 화면이 사라지고 생성 과정이 이어집니다.
3. 결과 화면에서 제목, 로그라인, 캐릭터, 1~16화 줄거리를 확인합니다.

지원 장르 예시: 로맨스, 판타지, 스릴러, 미스터리, SF, 일상, 무협, 호러, 성장, 시대극
