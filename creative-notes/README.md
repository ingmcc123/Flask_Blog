# 창작노트 · 리디 19금 현대로맨스

리디 플랫폼에 맞춘 **19금 현대로맨스** 기획 보조 웹앱입니다.

- 리디 키워드파인더·인기작 태그 기반 **키워드 추천**
- 제목 / 로그라인 / 캐릭터 프로필
- **70화 완결** 회차별 줄거리

## 실행

```bash
cd creative-notes
npm install
npm run dev
```

## 사용법

1. 트렌드 프리셋 또는 추천 키워드(#재벌남, #집착남, #계약연애/결혼, #고수위 등)를 고릅니다.
2. 톤(고수위·씬중심, 계약·선결후연 등)을 선택합니다.
3. **70화 노트 생성하기**를 누르면 기획안이 생성됩니다.

키워드 분류는 리디 로맨스 키워드 검색의 남주/여주/관계/수위 태그를 참고했습니다.
