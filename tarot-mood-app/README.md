# Mood Tarot — 지금 내 기분이 어때?

모바일 UX/UI 기준으로 제작한 타로 기분 앱입니다.

## 기능

1. **기분 입력** — "지금 내 기분이 어때?" 제목 아래 키워드 입력창
2. **키워드 분석** — 입력한 감정 키워드를 분석해 맞춤 타로카드 3장 표시
3. **카드 선택 & 해석** — 카드 한 장을 탭하면 아래에 해석과 조언 표시

## 실행 방법

```bash
cd tarot-mood-app
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 후, 모바일 뷰(375px)로 확인하면 최적입니다.

## 기술 스택

- React + TypeScript + Vite
- 모바일 퍼스트 반응형 UI (max-width 430px)
- SVG 기반 타로카드 일러스트 (18장 메이저 아르카나)
